# Multi-Class Benchmark Classification Pipeline

## Project Overview
This project implements an exploratory data analysis pipeline using the Iris dataset as part of the Datheon Machine Learning & Data Science Internship.

The objective is to understand the dataset and prepare it for developing supervised machine learning classification models.

## Dataset
The Iris dataset contains 150 observations belonging to three flower species:
- Setosa
- Versicolor
- Virginica

It includes four numerical features:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn
- Jupyter Notebook

## Work Completed
- Dataset loading and inspection
- Statistical summary
- Species distribution analysis
- Feature distribution histograms
- Pairplot visualization
- Correlation heatmap
